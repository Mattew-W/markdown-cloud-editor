## 5. 关键代码讲解（两个函数）

- `hash_password(password: &str)`：
  1. 用 `OsRng` 生成一个随机盐 `SaltString::generate`；
  2. 调用 `Argon2::default()`（默认就是 Argon2id）对密码做哈希；
  3. 输出 PHC 格式字符串 `$argon2id$v=19$m=...,t=...,p=1$<盐>$<哈希>`。
- `verify_password(password: &str, hash_str: &str)`：
  1. 先用 `PasswordHash::new(hash_str)` 解析字符串，格式不对立刻返回 `Err`；
  2. 调用 `verify_password` 校验，匹配返回 `Ok(())`，密码不匹配返回 `Err(Error::Password)`，函数把它转成 `Ok(false)`；
  3. 其他异常（参数不兼容等）继续向上抛，由调用方决定怎么处理。

## 6. 为什么不存明文密码

- 明文密码一旦数据库泄露，所有用户账号直接失守；
- Argon2id 是专门为密码存储设计的慢哈希算法，即使拿到哈希字符串，暴力破解也非常慢；
- 随机盐让两个相同密码的用户哈希串不同，攻击者无法靠"彩虹表"批量反查，也无法一眼看出哪些用户密码相同。

## 7. 遇到的问题与解决

- **问题 1**：第一次编译报错 `unresolved import argon2::password_hash::rand_core::OsRng`。
  原因：`argon2` 0.5 没有默认开启 `rand_core` 的 `getrandom` feature。
  解决：在 `Cargo.toml` 中显式加上 `rand_core = { version = "0.6", features = ["getrandom"] }`，并把 `OsRng` 从 `rand_core` 直接导入。
- **问题 2**：PowerShell 把 cargo 的 stderr 输出（编译进度）当成 NativeCommandError，导致 `cargo run` 退出码显示为 1。
  实际程序本身运行正常，四个案例全部按预期输出；这只是 PowerShell 对 stderr 的处理方式，不是程序错误。
