# M6 W2 检查记录

浏览器版本：Chromium 149.0.7827.55 (headless, Playwright)
运行环境：Node v22.22.2 / Windows 10.0.26300
运行方式：python -m http.server 9000 → http://127.0.0.1:9000/index.html

测试用例：

1. 动作：输入 111 → 点击【保存到本机】
   实际输出（复制自页面 #msg）：✅保存成功，保存时间：2026/10/20 14:14:56
   断言：输出须包含"保存成功"    结论：通过

2. 动作：刷新 → 点击【读取本机草稿】
   实际输出：✅读取成功，上次保存：2026/10/20 14:14:56
   断言：输入框回填 111          结论：通过

3. 动作：点击【读取本机草稿】（无草稿）
   实际输出：暂无本机草稿
   结论：通过

4. 动作：注入中文内容 → 保存 → 读取
   实际输出：读回内容与写入完全一致（48 字符，UTF-8 100 字节）
   结论：通过

5. 动作：注入损坏 JSON "{{{"
   实际输出：❌草稿内容格式损坏，无法读取
   结论：通过

6. 动作：模拟存储空间不足（QuotaExceededError）
   实际输出：❌存储失败：浏览器本地空间不足
   结论：通过

7. 动作：模拟存储不可用（SecurityError）
   实际输出：❌浏览器localStorage不可用
   结论：通过
