# 规则对照：W1 练习 → W2 正式输入规则

日期：2026-11-01。对象：独立 Rust 库 `document_validation`（仅用标准库），由 W1 的 `validation_demo` 升级而来。本文件只做规则对照，W1 源码保留在 `materials/M4/validation_demo`，不被覆盖。

## 1. 逐项规则变化

| 项目 | W1（练习，仅供对照） | W2（本周正式规则） | 说明 |
|---|---|---|---|
| 标题字符上限 | `MAX_TITLE_CHARS = 100` | `MAX_TITLE_CHARS = 255` | 标题先 `trim()`，再按 `chars().count()` 统计 Unicode 字符数，不是字节数 |
| 正文字节上限 | `MAX_BODY_BYTES = 100_000` | `MAX_BODY_BYTES = 262_144`（256 KiB） | 正文**不 trim**，直接用 `len()` 统计 UTF-8 字节数 |
| 默认标题 | `DEFAULT_TITLE = "未命名文档"`，空白/空标题都会被默认值替换 | `DEFAULT_TITLE = "未命名文档"`，**仅创建时 `title = None`（省略标题）才使用默认值** | 语义变化，见第 2 节 |
| 显式空串 `Some("")` | 被默认值替换，接受 | 返回 `ValidationError::EmptyTitle`，拒绝 | 创建、更新均拒绝 |
| 普通/全角空白标题（`"   "`、`"\u{3000}"` 等） | 被默认值替换，接受 | trim 后为空，返回 `EmptyTitle`，拒绝 | 创建、更新均拒绝；`trim()` 按 Unicode White_Space 判定，覆盖全角空格 `\u{3000}`、`\u{a0}` 等 |
| 更新时标题 | 与创建同一入口，空白可默认 | `validate_update` 中标题**必填**，空串/空白一律 `EmptyTitle` | 更新没有 `None` 入口，不存在默认 |
| 正常标题返回值 | 返回 trim 后的标题 | 返回 **trim 后**的 `String`（`validate_title` 的返回值） | `validate_update` 必须使用该返回值，不能只检查后又回填原始标题 |
| 正文返回值 | 原样保留 | **原样保留**，首尾空白、换行、制表符均不改动 | 前后规则一致 |

## 2. 空白标题语义的关键变化

- W1：`validate_document` 内部对标题 trim 后，只要结果为空（空串、普通空格、全角空格、制表符等），就替换成 `DEFAULT_TITLE`，所以“显式空白”不会报错。
- W2：区分“省略”与“显式提交空白”。
  - 创建接口 `normalize_create_title(Option<&str>)`：只有 `None` 表示调用方省略标题，才给默认值；`Some("")`、`Some("   ")`、`Some("\u{3000}")` 都走 `validate_title`，trim 后为空即 `EmptyTitle`。
  - 更新接口 `validate_update(title, content)`：标题是必填的 `&str`，没有 `None` 形态，空串或任何空白都返回 `EmptyTitle`。
- W1 的 100 / 100000 与“空白即默认”规则只用于对照，本库代码中不得混用；测试也不得再断言 W1 的旧行为。

## 3. 接口与类型（本周交付面）

- `pub fn validate_title(title: &str) -> Result<String, ValidationError>`
- `pub fn normalize_create_title(title: Option<&str>) -> Result<String, ValidationError>`
- `pub fn validate_content(content: &str) -> Result<(), ValidationError>`
- `pub fn validate_update(title: &str, content: &str) -> Result<ValidatedDocument, ValidationError>`
- `ValidatedDocument`：公有字段 `title: String`、`content: String`。
- `ValidationError`：`EmptyTitle`、`TitleTooLong { actual: usize, max: usize }`、`ContentTooLarge { actual: usize, max: usize }`。
- 结构体与错误枚举均 `derive(Debug, PartialEq, Eq)`；不引入主项目的 `AppError`，不改主项目现有签名。是否复用、如何适配由 M1 决定，本交付不声称已集成。

## 4. 本周明确不做的功能

仅用 Rust 标准库，不写也不引入：HTTP 服务/路由、数据库访问、DTO / Service / Repository 分层、登录认证、分页、权限、版本管理、并发、CRUD 增删改查。`main.rs` 只作规则演示，不是业务入口。不因角色叫“文档业务”而扩展范围。

若其他材料要求实现 Service 或 CRUD，该要求与本周“正式输入校验、不写 CRUD”的任务冲突，以本文件和阶段提示词为准，不据此替换本任务。
