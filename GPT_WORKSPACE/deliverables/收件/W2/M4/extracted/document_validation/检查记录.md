## 1. T1～T12 输入 / 预期 / 实际 / 断言

| ID | 调用接口与输入 | 预期 | 实际（见 6-test.log） | 关键断言 | 结果 |
|---|---|---|---|---|---|
| T1 | `validate_title("  中文标题  ")` | 接受，返回去空白标题 | `Ok("中文标题")` | `assert_eq!(result.unwrap(), "中文标题")` | PASS |
| T2 | `normalize_create_title(None)` | 接受，返回默认标题 | `Ok("未命名文档")` | `assert_eq!(result.unwrap(), DEFAULT_TITLE)` | PASS |
| T3 | `normalize_create_title(Some(""))` | 拒绝，空标题 | `Err(EmptyTitle)` | `assert_eq!(result, Err(ValidationError::EmptyTitle))` | PASS |
| T4 | 创建 `Some("   ")`、`Some("\u{3000}\u{a0}\t")`、`Some("\u{3000}")`；更新 `validate_update("   ", ..)`、`validate_update("\u{3000}\n", ..)` | 普通/全角空白均 `EmptyTitle`，创建与更新都覆盖 | 5 个调用全部 `Err(EmptyTitle)` | 5 条 `assert_eq!(.., Err(ValidationError::EmptyTitle))` | PASS |
| T5 | `validate_title(&"中".repeat(255))` | 接受，255 字符 | `Ok`，返回值 255 字符 | 先断言输入 `chars().count()==255`，再断言返回值 `chars().count()==255` | PASS |
| T6 | `validate_title(&"中".repeat(256))` | 拒绝，`TitleTooLong{actual:256,max:255}` | 同预期 | `assert_eq!(result, Err(TitleTooLong{actual:256,max:MAX_TITLE_CHARS}))` | PASS |
| T7 | `validate_content("")` | 空正文通过 | `Ok(())` | `assert_eq!(validate_content(""), Ok(()))` | PASS |
| T8 | `validate_content(&"a".repeat(262144))` | 262144 字节通过 | `Ok(())` | 先断言 `len()==262144`，再断言 `Ok(())` | PASS |
| T9 | `validate_content(&"a".repeat(262145))` | 拒绝，`ContentTooLarge{actual:262145,max:262144}` | 同预期 | `assert_eq!(.., Err(ContentTooLarge{actual:262145,max:MAX_BODY_BYTES}))` | PASS |
| T10 | `validate_content("中".repeat(87381)+"a")` 及再加一个 `"a"` | 前者恰好 262144 字节通过；后者 262145 字节拒绝 | 前者 `Ok(())`，后者 `Err(ContentTooLarge{actual:262145,..})` | 断言构造串 `len()==262144`、`Ok(())`；加一字符后 `len()==262145` 且对应错误 | PASS |
| T11 | `validate_update("  标题  ", "  正文\n\t")` | 标题返回 `"标题"`，正文首尾空白原样保留 | `Ok(ValidatedDocument{title:"标题", content:"  正文\n\t"})` | `assert_eq!(doc.title,"标题")`、`assert_eq!(doc.content, body)` | PASS |
| T12 | `validate_title("  "+"中"×255+"  ")` 与 `"  "+"中"×256+"  "` | 先 trim 再计数：255 通过、256 报 `TitleTooLong{actual:256,..}` | 同预期 | 接受值 `chars().count()==255`；超限值精确匹配错误枚举 | PASS |

补充说明：
- 创建标题统一走 `normalize_create_title`，正文统一走 `validate_content`，更新统一走 `validate_update`，四个公有接口均被真实调用，不存在“只测一个函数就声称全部接口验证”。
- T11 同时验证了 `validate_update` 使用的是 `validate_title` 返回的 trim 结果，而非原始输入；正文经 `validate_content` 后原样回填。
- 测试中未出现 W1 的 100 / 100000 阈值或“空白即默认”的旧断言。
