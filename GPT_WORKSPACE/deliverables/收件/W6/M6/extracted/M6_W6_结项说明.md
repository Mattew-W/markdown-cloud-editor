## 3. 浏览器与 HTTP 侧结论（摘要）

1. **在途继续输入**：点击保存后 60ms 继续输入，最终产生两次写入（v6→v7），末段追加文本落库，重载可见。
2. **切换文档**：A(v7)→B(v5)→A(v7)，切回后的基线与界面均为 v7，旧响应未污染。
3. **响应丢失**：同源入口把上游已返回 200 的 PUT 响应在客户端侧丢弃，界面进入“等待重试”，随后按“云端版本+正文”核对采用云端，云端版本仅 +1（未重复写入）。
4. **断网恢复**：停 Actix → “等待重试 / 网络中断，已在本地备份”，草稿 1 条；起 Actix → 自动重试成功 v4，草稿清空。
5. **跨账号**：B 对 A 文档的读/改/删全部 404，A 文档内容与版本不变。
6. **冲突**：同 `expected_version=1` 并发 PUT，恰 1 次 200 + 1 次 409（`server_version=2`），最终行与胜方一致；界面侧旧基准 v2 收到 409 后弹窗列出“云端 v3 / 本地 v2”。
7. **存储不足**：真实写满 localStorage 后输入，界面给出“本地备份失败：存储空间不足…”提示，内容留在编辑器，可一键下载（325 字节 md，正文完整）。
8. **多窗口与删除**：同账号两个会话的草稿键 session 段不同；云端 v2 时用 `expected_version=1` 删除被 409 拒绝，用 v2 删除 204 → 再读 404。
9. **预览与光标**：预览对 `<script>`、`onerror`、`javascript:` 链接全部清洗，标题按纯文本渲染；自动保存期间焦点与光标位置连续推进未被替换。
10. **服务重启**：停/起 Actix 后刷新页面仍读出 v4/v7/v8。
