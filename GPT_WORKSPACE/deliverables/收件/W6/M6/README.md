## 修复的两处真实缺陷

### F-01 JSON > 2 MiB 返回 400（应 413）

**实测确认**：400 + `BAD_REQUEST: JSON payload (2400028 bytes) is larger than allowed`

**她的建议不准确**（说"把 `Overflow` 映射到 413"，但代码已经映射了）。**真正根因**：

actix-web 4.17 的 `JsonPayloadError` 有**两个**溢出变体——
- `OverflowKnownLength`（**带 Content-Length 时触发**）
- `Overflow`（分块传输时触发）

代码只匹配了后者，而浏览器/常规客户端都带 `Content-Length` → 落到 `other` → 400。

**修复**：两处同时匹配两个变体。**实测 → 413 `PAYLOAD_TOO_LARGE`** ✅

### F-02 非法 UUID 返回 404 纯文本（应 400 JSON）

**实测确认**：404 + `text/plain` + `UUID parsing failed: invalid character`

**修复**：给 documents 路由挂 `PathConfig::error_handler` → 400 JSON。
「资源不存在」仍由 handler 的 `AppError::NotFound` 返回 404，语义分离。

**实测 → 400 + `application/json`** ✅

**修复不破坏基线**：3373a9e 上复跑仍 **118/0/58**。
