## 统一复跑与演示

1. 检出固定 SHA，按仓库 README 启动专用 PostgreSQL 17 和 Actix。配置同源本地入口，静态文件来自 `frontend/`，`/api/` 转发到 Actix。部署拓扑见 `docs/ARCHITECTURE.md` §10。
2. 在干净检出运行 `cargo fmt --check`、`cargo clippy --locked --all-targets -- -D warnings`、`cargo test --locked --all-targets`、`cargo doc --locked --no-deps`。连接专用测试库后执行 `cargo test --locked --all-targets -- --ignored`。运行 `npm ci --prefix frontend`、`npm test --prefix frontend` 和 `docs/DATABASE.md` §7.4 的 SQL 入口。
3. 浏览器用两个独立会话跑注册和登录、创建并编辑、保存、另一会话读取、冲突处理和断网恢复。重启 Actix 后重新读取，最后删除。演示结果逐项映射 [T01–T15 验收矩阵](W6_验收矩阵.md)，标注浏览器自动化、人工操作及所用数据。
4. 在新环境完成彩排，现场演示、运行说明、技术报告、答辩材料及成员确认都准备好后，由 M1 汇总结项。课程要求公网部署时，带环境及访问验证证据。
