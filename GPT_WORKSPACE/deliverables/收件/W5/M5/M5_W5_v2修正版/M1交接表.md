## 2. 同步状态徽标（前端分支齐全，真实可见性待联调）

`updateSyncBadge`（app.js 第 154 行起）内联映射七状态，源码分支齐全（用例 21 通过）：

| SyncState 常量 | 徽标/提示含义 | 当前覆盖 | 待 M1 联调复核 |
|---|---|---|---|
| `SYNCED` | 已同步 | 真实页面初始态观察到「已同步」 | 后端同步成功后的真实徽标切换 |
| `DIRTY` | 有未保存修改 | 现有编辑事件用例覆盖 | 输入后徽标是否及时转为待保存 |
| `SAVING` | 保存中 | 源码分支存在；jsdom 已断言分支齐全 | 真实在途 PUT 期间「保存中」提示可见性 |
| `RETRY_WAIT` | 重试等待 | 源码分支存在；同步测试覆盖退避逻辑 | 网络失败后重试倒计时/提示可见性 |
| `AUTH_REQUIRED` | 未登录/鉴权失效 | 无 token 自动弹登录框（基线既有行为） | 401 后徽标与登录框联动 |
| `CONFLICT` | 版本冲突 | 弹窗两按钮 DOM 行为已测 | 真实 409 弹出冲突弹窗与 serverVersion 展示 |
| `INVALID` | 输入/响应非法 | 源码分支存在；API 错误映射用例覆盖 | 非法响应下徽标与提示 |

## 4.1 契约冲突与跨模块缺口记录（本轮新增，任务书 M5-W5-04 要求）

本节记录**审计阶段发现的契约文本冲突**与**前端无法自行闭合的缺口**，
交 M1 裁决。每条给出：冲突点 / 证据 / 影响 / 期望 / 实际。

### 冲突 C-1：存储失败横幅文案与 `docs/INTERFACES.md` §2.5 冻结文案不一致

| 要素 | 内容 |
|---|---|
| 冲突点 | 冻结文案要求按 `reason` 显示四种固定文案；前端实际是**单一模板 + 原始 reason 码** |
| 证据（契约） | `docs/INTERFACES.md:284-287` —— `quota` → 「本地备份失败：存储空间不足」；`unavailable` → 「本地备份失败：浏览器禁止本地存储」；`corrupt` → 「本地备份已损坏，已忽略」；`serialize` → 「本地备份失败：内容无法序列化」 |
| 证据（实现） | `frontend/js/app.js:113-117` —— `onStorageFailure` 用 `本地备份失败（${info.reason}），内容仅存在于内存中，请立即下载。` 模板，`reason` 为原始英文码 |
| 影响 | 用户看到的是「本地备份失败（quota）」而非「本地备份失败：存储空间不足」，**可读性下降**；四种 reason 在界面上无法区分 |
| 期望 | 四种 reason 各自显示契约冻结的中文文案 |
| 实际 | 统一模板 + 原始 reason 码 |
| 责任方 | M5 需按契约改为四分支映射；**M1 需确认契约文本是否为最终版本**（若契约已变更，则双方都需同步） |

### 缺口 G-1：冲突弹窗为两按钮接口，无「取消」分支

| 要素 | 内容 |
|---|---|
| 缺口 | 基线弹窗只有「重新载入云端最新版本 (推荐)」「强制以本地内容覆盖云端」两个按钮，**无取消按钮** |
| 证据 | `frontend/js/app.js` 冲突弹窗渲染段；`screenshots/冲突弹窗_两按钮接口现状.png`；`docs/SYNC.md` §6.2 的冲突分支要求包含「取消保持当前内容」 |
| 影响 | 用户无法在冲突时选择「保留本地编辑、暂不处理」——只能覆盖或重载，两种都会改变本地内容 |
| 期望 | 第三个「取消」按钮，点击后保持当前内容不变、不发 PUT、不清草稿 |
| 实际 | 按钮缺失 |
| 责任方 | M5 补按钮与分支；W4 候选 `ui-feedback.js` 已有四选项 + 取消，**是否接入基线由 M1 决策**（见 §4） |

### 缺口 G-2：存储失败条的真实显示路径未能在 jsdom 中验证

| 要素 | 内容 |
|---|---|
| 缺口 | 「存储不可用 → 失败条显示 + 下载入口可用」这条链路依赖**真实浏览器存储被禁用**（无痕模式 / 站点数据被拒 / 配额耗尽） |
| 证据 | `frontend/js/tests/app.state.w5.test.js` 第 3 个用例注释；jsdom 的 localStorage 是内存实现，mock 模拟只会得到「写入失败被 catch 但状态未流转」的假象 |
| 影响 | 该验收点在 DOM 测试层**只验证了结构可达性**，未验证真实显示 |
| 期望 | 真实浏览器中禁用站点数据后，底部失败条出现且「下载当前 Markdown」可下载当前内存内容 |
| 实际 | **未执行**（已如实标注） |
| 复跑入口 | Chrome 无痕窗口打开 `http://127.0.0.1:8080/` → 登录 → 输入正文 → 在 DevTools Application 面板禁用站点数据 → 观察底部失败条与下载按钮 |
| 责任方 | M5 或 M1 在真实浏览器复核 |
