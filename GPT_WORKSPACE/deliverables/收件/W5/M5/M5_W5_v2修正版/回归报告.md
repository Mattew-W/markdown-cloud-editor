## 3. 本轮新增用例清单（13 条）

### 3.1 编辑器生命周期 `js/tests/editor.lifecycle.w5.test.js`（4 条）
1. 两实例并存：A 的输入不通知 B，B 的预览不被 A 改动。
2. `setValue` 不重建输入节点，节点引用保持不变。
3. `setValue` 不主动 focus / select，不抢占输入焦点。
4. 真实 DOM 上 destroy 后派发 input 不再通知，监听已移除。

### 3.2 预览与生产 vendor `js/tests/vendor.preview.w5.test.js`（5 条）
1. 生产 vendor：普通 Markdown 标题与合法 https 链接正常保留。
2. 生产 vendor：单行 `javascript:` 链接保留 a 与文本，危险 href 被剥离。
3. 生产 vendor：连续 HTML block 无 script、无事件属性、无残留链接。
4. 版本闭环：`package.json` = node_modules 实测 = vendor 本地托管版本（marked 12.0.2 / DOMPurify 3.3.3）。
5. `index.html` 实际加载本地 vendor 路径，不引用外部 CDN 脚本。

> 路径区分：基线既有安全测试走 npm 测试依赖（`import { marked }` / `import createDOMPurify from "dompurify"`）；本文件直接惰性读取并执行页面 `vendor/` 下的生产 min.js，走 `marked.parse → DOMPurify.sanitize → innerHTML` 真实链路。

### 3.3 冲突弹窗与可见状态 `js/tests/conflict.w5.test.js`（4 条）
1. 点「重新载入云端」：弹窗关闭，回调走 `resolveReload(`。
2. 点「强制本地覆盖」：弹窗关闭，回调走 `resolveOverwrite(`。
3. 基线冲突弹窗为两按钮接口，不含「取消」按钮（差异记录交 M1）。
4. 七状态徽标分支在源码中齐全：synced / dirty / saving / retry / auth / conflict / invalid。

## 4. 真实浏览器自动化实测记录

静态服务以工作副本 `frontend` 目录为根，`127.0.0.1:8080` 提供 text/javascript 静态资源，ES module 可加载。

- 初始状态：徽标显示「已同步」，状态栏「系统就绪」；`window.marked.parse` 与 `window.DOMPurify.sanitize` 可用；控制台无页面脚本错误。
- 输入含标题、加粗、合法链接、危险 `javascript:` 链接、HTML 块的 Markdown 后：预览渲染与净化结果与测试断言一致——合法链接保留 href；危险链接 href 被剥离、文本保留；页面无 `<script>`、无 `onerror` 等事件属性。
- 未登录进入会自动弹出登录弹窗：`initApp` 无 token 走 `showAuthModal(false)`，属基线既有行为，非错误。
- 冲突弹窗 DOM 调出后两按钮文案核对一致，点击后均关闭。
- 控制台一条 404 来自测试夹具 `<img src=x>` 占位图加载，非页面脚本错误；Immersive Translate 扩展的 `Failed to fetch` / LanguageDetector 提示为浏览器扩展噪声，不计入页面错误。
