## 5. Understanding Questions — Reference Points (English)

The following reference points are provided by the AI for study; they do not replace the student's own answer. The student confirms understanding by signing below.

Q1. Why is an explicit blank title rejected instead of being defaulted?

`None` means the title was omitted, so the server may safely apply the default title. `Some("")` or `Some("   ")` means a title was explicitly submitted but is invalid after trimming. This is a client error and must be returned so the caller can correct it, rather than being silently replaced. Silently defaulting would hide missing front-end validation or accidental input and would make the stored title inconsistent with what the user actually saw.

Q2. Why do we persist the trimmed value instead of only validating it?

It keeps the validated value and the stored value identical under a single rule. If validation only checked the title without returning it, every caller would have to trim again, which is easy to miss or implement inconsistently, allowing a title with surrounding whitespace to be saved despite passing validation. Returning the normalized string lets callers use it directly and keeps the rule maintained in one place.
