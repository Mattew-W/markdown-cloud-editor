# 课程交件与审核归档

本目录保存课程组员的历史交件、审核记录和返工材料。归档内容用于追溯，不是生产代码来源，也不参与主项目构建。

主项目当前代码位于仓库根目录的 src、frontend、migrations 和 tests。

## W1 归档

- **M4**：收件目录包含原始提取件、M1 的代码级修正版、检查记录、交付说明和审计报告。审计报告记录了原交件不符合 W1 练习要求；修正版不代表 M4 的 validation_demo 练习已完成。详见 [M4 归档说明](deliverables/收件/W1/M4/README.md)。
- **M5**：收件目录包含 W1 v2 前端界面样例；同级 deliverables 中保留审计报告和返工意见。请以这些记录中的审核结论为准。
- **M6**：W1 草稿模块的原始收件保留在 [M6 收件目录](deliverables/收件/W1/M6/正式模块草案_frontend/)；主项目当前模块位于仓库根目录的 frontend/js/。

M4 原始任务书没有随本次归档提交；归档说明和审计报告注明了相应要求及评估依据。

为发布到公开仓库，审核材料中的本机绝对路径和微信标识已替换为脱敏占位符；交件内容和审核结论保留。
