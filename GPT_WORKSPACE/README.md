## 归档原则

W1 材料反映收件时的状态。历史审计意见不自动等同于当前项目状态；生产实现以仓库根目录的 src/、frontend/、migrations/ 和 tests/ 为准。

新增到公开仓库的交件副本已移除个人身份信息和本机路径。M6 原始压缩包和含私人文件位置的 M3 解压脚本未公开。M1 阶段报告为 2026-10-21 的历史快照。
